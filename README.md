## 🌟 Fitur Utama Aplikasi

1. **Kamus Kosakata Interaktif & Flashcard 3D**:
   - **7 Kosakata Alat Tulis**: *Daftarun (Buku Tulis), Qalamun (Pena/Pulpen), Qalamu Rasaasin (Pensil), Mistaratuun (Penggaris), Mimhaatun (Penghapus), Miqassun (Gunting), Haqiibatun (Tas)*.
   - **15 Kosakata Benda di Kelas**: *Saa'atun (Jam), Mirwahatun (Kipas Angin), Baabun (Pintu), Sabbuuratun (Papan Tulis), Khizaanatun (Lemari), Maktabun (Meja), Kursiyyun (Kursi), Naafizatun (Jendela), Misbaahun (Lampu), Jidaarun (Tembok/Dinding), Bilaatun (Lantai), Zujaajun (Kaca), Raffun (Rak), Miknasatun (Sapu), Mazbalatun (Tempat Sampah)*.
   - Dilengkapi tulisan berharakat lengkap, transliterasi latin, arti, dan **Audio Pelafalan Arab Asli (Text-to-Speech)**.
   - Mode **Flashcard 3D** yang dapat dibalik untuk belajar mandiri siswa di rumah.

2. **Eksplorasi Teks Cerita ("فِي فَصْلِيْ")**:
   - Teks cerita interaktif sesuai materi Asesmen:
     - *Haadzaa faslii. Fil-fasli maktabun wa kursiyyun wa sabbuuratun.*
     - *'Alal-jidaari saa'atun wa misbaahun.*
     - *Fii haqiibatii daftarun wa qalamun wa qalamu rasaasin wa mistaratun.*
   - Klik pada kata Arab untuk membuka modal arti dan kategori bendanya.
   - Tombol dengarkan bacaan cerita per kalimat atau seluruh teks sekaligus.

3. **Papan Tulis Digital Maharatul Kitabah (Khat Naskh Pad)**:
   - Canvas ramah anak (mendukung layar sentuh tablet/HP dan mouse laptop).
   - Fitur bayangan tulisan (*tracing template*) untuk meniru bentuk huruf dan kata Arab secara presisi.
   - Garis panduan dasar (*baseline*) Khat Naskh.
   - Game interaktif puzzle menyambung huruf hijaiyah terpisah.

4. **Bank Soal Lengkap (37 Butir Soal)**:
   - Format A: Soal Pemahaman Teks Cerita (sesuai kisi-kisi asesmen resmi).
   - Format B: Maharatul Kitabah (Menyambung Huruf Hijaiyah).
   - Format C: Ikmalul Huruf (Melengkapi huruf yang hilang).
   - Format D: Pilihan Ganda Kosakata & Terjemahan.
   - Koreksi otomatis, feedback instan, pembahasan mendalam, dan selebrasi konfeti jika mencapai nilai tinggi.

5. **Simulasi Asesmen Tengah Semester (ATS)**:
   - Ujian berbasis waktu (timer 30 menit) dengan 15 butir soal pilihan acak.
   - Laporan hasil ujian lengkap dengan skor skala 100, predikat Islami (*Mumtaz, Jayyid Jiddan, Jayyid, Maqbul*), dan review jawaban siswa.

6. **Fitur Cetak Lembar Kerja / Worksheet PDF**:
   - Format A4 siap cetak dengan Kop Surat resmi **SDIT TAHFIDZ BINTANGKU KOTA PROBOLINGGO**.
   - Kolom identitas siswa (Nama, No Absen, Tanggal, Kotak Nilai, Paraf Guru).
   - Dilengkapi garis putus-putus untuk lembar jawaban menulis siswa.

## 🚀 Cara Menjalankan Aplikasi

Aplikasi ini bersifat mandiri (*standalone Single Page Application*) tanpa perlu instalasi server yang rumit:

1. **Buka Langsung di Browser**:
   - Cukup klik ganda (*double click*) file `index.html` atau buka browser (Google Chrome, Microsoft Edge, atau Safari).
   - Atau buka file melalui path:  
     `file:///C:/Users/Sekawan/.gemini/antigravity/scratch/bahasa-arab-sdit3/index.html`

2. **Dukungan Perangkat**:
   - Komputer / Laptop Guru (sangat cocok ditampilkan di proyektor kelas).
   - Tablet / Layar Sentuh (sangat baik untuk latihan menulis di Papan Tulis Kitabah).
   - Smartphone (tampilan responsif dan mudah digunakan).
